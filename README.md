# Project: Members only

The project is built with HTML, CSS, JavaSCript, Postgres database, Express, Express Session and Passport.js.  
This project demonstrates form validation, user authentication, CRUD operations on User, clean code structure, problem solving skill.

---

## ✨ Features

- 🎮 **Register, login, logout users**
- 💻 **Create/Read/Update/Delete posts**

---

## 🛠️ Tech Stack

- **Language:** HTML, CSS and JavaSCript
- **Framework:** Express
- **Database:** Postgres 
- **Other tools:** Visual Studio Code
- **Node Packages:** express, ejs, pg, dotenv, express-session, passport.js

---

### Install necessary pacakges
npm install

### Create .env file
HTTP_PORT
DATABASE_URL="postgresql://[yours]:[yours]@localhost:5432/top_member_only"
